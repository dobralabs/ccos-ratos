# RatosOS 2.1 (setembro de 2026)

Uma correção de segurança e um opcional novo. A primeira mudança vale pra **todo mundo que
instalou a 2.0 pelo zip da plataforma**. Instruções gerais pro agente em `COMO-ATUALIZAR.md`.

---

## 1. A trava do `.gitignore` volta pro sistema

- **O que é:** o `.gitignore` é o arquivo que impede o `/syncar` de mandar pro GitHub o `.env`
  (onde moram as chaves), vídeo, zip e as configurações desta máquina.
- **Por quê:** até 29/09/2026 o zip do kit baixado na plataforma saía **sem** esse arquivo (o
  empacotador tirava ele de toda skill). Quem instalou por ali e usou o `/syncar` mandou tudo pro
  GitHub, inclusive o `.env`, se existia.
- **Te afeta se:** não existe `.gitignore` na raiz do sistema (`ls .gitignore`).
- **Como aplicar:** copiar `sistema/templates/gitignore.txt` do kit pra `.gitignore` na raiz do
  sistema (e o próprio `gitignore.txt` pra pasta de modelos, pra próxima vez). Se o sistema já está
  no GitHub, listar o que subiu e agora ficaria de fora:
  `git ls-files -ci --exclude-standard`. Mostrar a lista e, com o sim, tirar do GitHub **sem apagar
  do computador**: `git rm --cached <arquivo>` e depois `/syncar`.
  Se na lista tem `.env` ou arquivo com chave: **a chave vazou pro histórico do repositório**, e
  tirar o arquivo não apaga o histórico. Dizer isso com todas as letras e orientar a trocar cada
  chave no serviço dela (gerar uma nova, apagar a antiga) e pôr a nova só no `.env`. Se o
  repositório é **público**, é urgente. Trocar também o `/syncar` pelo do kit (ele agora se recusa a
  enviar sem `.gitignore`).
- **Como testar:** `git check-ignore -q .env && echo protegido` responde `protegido`;
  `bash <kit>/sistema/scripts/conferir-kit.sh` de dentro da instalação não acusa o `.gitignore`.

## 2. Envio automático pro GitHub (opcional)

- **O que é:** `sistema/scripts/auto-sync.sh`, um script que o computador roda sozinho a cada X
  minutos: traz o que a equipe mandou e envia o que mudou aqui. Na dúvida, ele **para e deixa um
  recado** em `_memoria/recados/` (o `/iniciar` mostra), e o `/syncar` ganhou o Fluxo E pra resolver
  junto com você. Nunca força, nunca junta arquivo sozinho, e confere chave e arquivo pesado antes
  de enviar.
- **Por quê:** quem trabalha em equipe (ou em dois computadores) esquece de sincronizar, e o outro
  lado trabalha em cima de versão velha.
- **Te afeta se:** o sistema está no GitHub e você quer que ele sincronize sem pedir. Senão, pule:
  o script fica parado, ninguém chama ele.
- **Como aplicar:** copiar `auto-sync.sh` pra pasta de scripts do sistema e trocar o `/syncar` pelo
  do kit. **Ligar** (agendar no computador) é a última etapa da receita "Ratos OS no GitHub, com a
  equipe", na plataforma: ela configura o agendador no Mac, Windows ou Linux, testa e registra em
  `_contexto/automacoes.md`. Não ligar sem ela.
- **Como testar:** `bash sistema/scripts/auto-sync.sh; echo $?` responde `0` e
  `.git/auto-sync-ultima-rodada` mostra a hora de agora.
